# Haitham Hattan — Personal Portfolio

A modern, fast, multilingual personal portfolio website for [haithamhattan.sa](https://haithamhattan.sa/), showcasing professional experience, projects, awards, and skills.

## Features

- Multilingual: Arabic (default), English, Chinese — switchable from the navbar and persisted via `localStorage`
- RTL/LTR handling with per-language fonts
- Light / dark theme with a toggle (respects system preference)
- SEO-ready: meta tags, Open Graph, Twitter Card, JSON-LD `Person` schema, hreflang, `sitemap.xml`, `robots.txt`
- Fully inline SVG icons (LinkedIn, GitHub, X, WhatsApp) — no external icon CDN required
- Scroll-reveal animations, active-section navigation, back-to-top button
- Responsive layout for all screen sizes
- ATS-formatted English resume available for download

## Technologies

- HTML5, CSS3, Vanilla JavaScript (no build step)
- Google Fonts: Cairo, Inter, Noto Sans SC, JetBrains Mono

## Sections

- Hero + impact statistics
- About
- Experience
- Projects (6 featured + more)
- Awards
- Certifications
- Skills
- Education & Volunteering
- Contact

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. Edit content in `index.html`, `styles.css`, and translations in `script.js`
